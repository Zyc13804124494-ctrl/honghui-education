# 鸿慧教育学生作业管理工具

一个适合小学托管机构使用的轻量作业管理工具。支持学生名单管理、每日作业完成记录、老师批改记录、备注、搜索与年级筛选。

## 运行方式

1. 在 VS Code 中打开本文件夹。
2. 打开终端，执行：

```bash
npm install
npm run dev
```

3. 根据终端提示打开本地地址（通常是 `http://localhost:5173`）。

## 说明

- 数据保存在当前浏览器的 `localStorage` 中，刷新页面不会丢失。
- 点击作业状态可以循环切换状态；备注在输入完成后自动保存。
- 项目为前端单页应用，无需配置数据库或后端服务。
